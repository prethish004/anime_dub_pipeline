# whisper_env — Steps 1, 2, 3

# Verified working combination as of March 2026.
#
# Key version decisions:
#   torch 2.5.1       — pyannote 4.x pins torch==2.8.0 exactly,
#                        which causes the same weights_only crash
#                        you already hit with XTTS. torch 2.5.1
#                        avoids ALL of those issues.
#   pyannote 3.3.2    — last version before the torch==2.8.0 pin.
#                        Works reliably with torch 2.5.1.
#   whisperx 3.8.2    — latest stable. Install with --no-deps
#                        (see install order below) so it does not
#                        force-upgrade torch.
#   transformers 4.44 — compatible with whisperx + pyannote 3.3.2.
#                        whisperx 3.8.2 requires >=4.48 but 4.44
#                        works in practice for Steps 1-3.
#
# HOW TO CREATE whisper_env (run in order):
# ------------------------------------------
#   python -m venv whisper_env
#   .\whisper_env\Scripts\activate          (Windows)
#   source whisper_env/bin/activate         (Linux/macOS)
#
#   # Step A: install torch FIRST before anything else
#   pip install torch==2.5.1 torchaudio==2.5.1
#
#   # Step B: install whisperx WITHOUT letting it upgrade torch
#   pip install whisperx==3.8.2 --no-deps
#
#   # Step C: install the rest from this file
#   pip install -r requirements_whisper_env.txt
#
# ============================================================
